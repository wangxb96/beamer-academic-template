# Contributing to Academic Beamer Template

Thank you for considering contributing to this project! This document provides guidelines for contributing.

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion:

1. Check if the issue already exists in the [Issues](../../issues) section
2. If not, create a new issue with:
   - Clear title describing the problem
   - Steps to reproduce (for bugs)
   - Expected vs. actual behavior
   - LaTeX distribution and version
   - Sample code if applicable

### Suggesting Enhancements

For new features or improvements:

1. Open an issue with the "enhancement" label
2. Describe the feature and its use case
3. Provide examples if possible
4. Explain why it would be useful to other users

### Pull Requests

1. **Fork the repository**
   ```bash
   git clone https://github.com/yourusername/beamer-academic-template.git
   cd beamer-academic-template
   ```

2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes**
   - Follow existing code style
   - Test your changes thoroughly
   - Update documentation if needed

4. **Commit your changes**
   ```bash
   git add .
   git commit -m "Add feature: brief description"
   ```

5. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Create a Pull Request**
   - Provide a clear description of changes
   - Reference any related issues
   - Include before/after examples if applicable

## Development Guidelines

### Code Style

- Use consistent indentation (4 spaces)
- Comment complex LaTeX code
- Keep lines under 100 characters where possible
- Use meaningful variable/macro names

### Testing

Before submitting:

1. Compile with `pdflatex` successfully
2. Test with both presentation and handout modes
3. Verify all examples work correctly
4. Check for any LaTeX errors or warnings

### Documentation

- Update README.md for significant changes
- Add examples for new features
- Keep QUICKSTART.md current
- Comment complex LaTeX macros

## Types of Contributions

### Code Contributions
- New features or improvements
- Bug fixes
- Performance optimizations
- Code refactoring

### Documentation
- Fixing typos or clarifying instructions
- Adding examples
- Translating documentation
- Improving comments in code

### Examples
- New example presentations
- Use case demonstrations
- Template variations
- Style customizations

## Community Guidelines

- Be respectful and constructive
- Help others learn LaTeX and Beamer
- Share knowledge and best practices
- Give credit where due

## Questions?

If you have questions about contributing:
- Open a discussion in Issues
- Check existing documentation
- Ask in the community forum

Thank you for helping improve this template! 🙏

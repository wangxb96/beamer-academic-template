# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-11-17

### Added
- Initial release of Academic Beamer Template
- Basic slide template with 16:9 aspect ratio
- Custom footline with author, title, and page numbers
- Support for mathematical equations (amsmath, amssymb)
- Algorithm typesetting (algorithm, algpseudocode)
- Figure management (graphicx, subfigure)
- Table formatting (booktabs, multirow)
- Bibliography support (natbib)
- Complete example presentation
- Comprehensive README with documentation
- Quick start guide
- MIT License
- .gitignore for LaTeX files
- figures/ directory for images

### Features
- Clean, minimal design
- Progressive reveal with \pause
- Two-column layout support
- Handout mode option
- Customizable colors
- Multiple math packages
- TikZ support for diagrams
